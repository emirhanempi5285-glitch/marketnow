# Cross-Platform Launch Strategy

## Why Cross-Platform?
- Each platform reaches different audiences
- Amazon: Buyers with purchase intent
- Gumroad: Creators and digital product collectors
- Hotmart: Portuguese/Spanish infoproduct buyers
- Shopify: Brand-conscious direct buyers
- Same content → different format → maximum revenue surface

## Platform Approval Times
| Platform | Approval Time | Notes |
|----------|--------------|-------|
| Gumroad | Instant | No review process |
| Hotmart | 2-24 hours | Content moderation check |
| Shopify | Instant (store) | Digital products auto-approved |
| KDP (ebook) | 12-72 hours | Full review by Amazon |
| KDP (paperback) | 24-72 hours | Print quality check |
| KDP (hardcover) | 48-96 hours | Additional review step |

## Content Repurposing Matrix
Use the same core content across all platforms with format adaptation:

```
Core Content: "50 Animal Mandala Designs"
├── KDP → Full coloring book (100 pages, 8.5×11, paperback + ebook)
├── Gumroad → Digital PDF download (50 designs, printable, $9)
├── Hotmart → "Mandala Mastery Course" (video lessons + PDF designs, $67)
└── Shopify → Individual design bundles by theme ($3-$19 each)
```

Core Content: "Notion CRM Template"
├── Gumroad → Full template pack ($29)
├── KDP → "The Complete Notion CRM Guide" ebook ($9.99)
├── Hotmart → "CRM Automation for Small Business" course ($97)
└── Shopify → Template + video course bundle ($49)

## Launch Timing

### Standard Launch (7-day window)
```
Day -14: Market research & content creation begins
Day -7: Platform-specific versions created
Day -5: Covers, previews, video assets generated
Day -3: Listings written, email sequences set up
Day -1: Gumroad goes live
Day 0: Hotmart goes live (announce to email list)
Day +1: KDP submitted
Day +3: KDP live
Day +5: Shopify live
Day +7: Affiliate recruitment starts on Hotmart
Day +14: Performance review & A/B testing
```

### Accelerated Launch (48 hours)
For time-sensitive content (trending topics, news events):
```
Hour 0: Content creation
Hour 6: Gumroad live (instant)
Hour 12: Hotmart submitted
Hour 18: KDP submitted (draft)
Hour 24: Hotmart live (if approved)
Hour 36: KDP live (if approved)
Hour 48: Shopify live, all platforms active
```

## Cross-Promotion Tactics
1. **KDP:** Add "Free Bonus" QR code → Gumroad (email capture)
2. **Gumroad:** Thank-you page → Hotmart upsell at 50% off
3. **Hotmart:** Checkout page → Shopify store (merch & physical)
4. **Shopify:** Post-purchase email → KDP recommendation

## Pricing Strategy Across Platforms
- **KDP (ebook):** $6.99-$9.99 (70% royalty tier)
- **KDP (paperback):** Cost + 40% margin
- **Gumroad:** $9-$29 (1-click checkout, lower friction)
- **Hotmart:** $47-$197 (higher perceived value, affiliate-driven)
- **Shopify:** $5-$49 (discovery via SEO and social)

## Performance KPIs by Platform
| Platform | Primary KPI | Secondary KPIs |
|----------|-------------|----------------|
| KDP | BSR (Bestseller Rank) | Page reads (KU), reviews |
| Gumroad | Conversion rate | Email capture, upsell rate |
| Hotmart | Commission volume | Affiliates recruited, refund rate |
| Shopify | ROAS | AOV (Avg Order Value), CLV |

## Avoid These Mistakes
1. **Same title everywhere** - Optimize for each platform's keyword ecosystem
2. **Same price everywhere** - Each platform has different perceived value
3. **Same content format** - Adapt to platform consumption habits
4. **No tracking** - Use UTM parameters on every cross-link
5. **Ignoring review windows** - Hotmart reviews content, KDP reviews formatting
6. **Selling KDP-only rights** - Don't list the same PDF on Gumroad that you have on KDP Select
