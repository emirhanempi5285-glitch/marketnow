# Hotmart Launch Checklist

## Pre-Launch (Day -30 to Day -7)

### Product Setup
- [ ] Title optimized for search (include keyword + benefit)
- [ ] Sales page written with conversion template
- [ ] Module structure complete (minimum 4 modules, 20 lessons total)
- [ ] Hosting platform confirmed (Hotmart Sparkle, Teachable, or external)
- [ ] Test video links work (no broken HTML5 embeds)
- [ ] Checkout flow tested with sandbox card
- [ ] Refund policy configured (7-day default)
- [ ] Display price set + promotional price
- [ ] Recurring billing configured for memberships
- [ ] Multiple currencies enabled (USD, BRL, EUR, MXN, COP)

### Affiliate Setup
- [ ] Commission rate set (50-60% recommended)
- [ ] Affiliate cookie duration set to 30 days (max)
- [ ] Affiliate area configured with swipes, banners, email templates
- [ ] Top affiliates identified and contacted (private offer: 70%+ commission)
- [ ] Affiliate referral link generated (trackable UTM)

### Asset Generation
- [ ] Sales thumbnail (16:9, 1280×720px minimum)
- [ ] Hotmart Sparkle trailer video (60-90 seconds)
- [ ] Product preview (first 3 lessons free)
- [ ] Bonuses designed (lifetime value adders)
- [ ] Email swipe templates for 5-day launch sequence
- [ ] Social media graphics (square, story, banner)
- [ ] Blog post / landing page for SEO

## Launch Day (Day 0)

### Activation
- [ ] Product set to "Active" in Hotmart dashboard
- [ ] Test purchase made through affiliate link
- [ ] Sales notification verified (email + Hotmart mobile)
- [ ] Checkout flow tested on mobile
- [ ] Checkout flow tested on desktop
- [ ] Conditional offers configured (upsell, downsell)

### Affiliate Activation
- [ ] Email blast to affiliate list (private + public)
- [ ] Affiliate contest announced (prizes for top 3)
- [ ] Affiliate training webinar scheduled (Day +3)
- [ ] Affiliate toolkit posted in producer area

### Launch Emails (5-Day Sequence)

**Day 0 - Announcement:**
```
Subject: 🔥 NEW: [Product Name] just launched!
Body: Pain → Solution → 50% off for first 48 hours
CTA: Get it now
```

**Day 1 - Value + Social Proof:**
```
Subject: See what early buyers are saying
Body: 2-3 testimonials + key module breakdown
CTA: Join 100+ students
```

**Day 2 - Bonuses Close:**
```
Subject: [Name], your bonuses expire in 24 hours
Body: Each bonus worth $XXX, all included
CTA: Claim bonuses now
```

**Day 3 - Price Increase:**
```
Subject: Price goes up tonight
Body: Final chance at launch price
CTA: Lock in before increase
```

**Day 4 - Last Call:**
```
Subject: Last chance - launch price ends
Body: Countdown timer + FAQ objection handling
CTA: Final enrollment
```

## Post-Launch (Day +1 to +30)

### Optimization
- [ ] Conversion rate analyzed (target: >3%)
- [ ] Affiliate performance reviewed (top 10 affiliates)
- [ ] Sales page A/B tested (headline, CTA, pricing)
- [ ] Refund requests analyzed for quality issues
- [ ] Student feedback collected (survey)
- [ ] Content updated based on feedback

### Growth
- [ ] Webinar funnel created (60-minute value + offer)
- [ ] Content marketing (YouTube, TikTok, blog)
- [ ] Paid ads tested (Facebook Ads, Instagram, Google)
- [ ] Joint venture partnerships secured
- [ ] Evergreen launch funnel automated

## Common Hotmart Mistakes
1. **No proofreading** - Typos in sales page kill conversions
2. **Weak hook** - First 3 lines must grab attention
3. **Low affiliate commission** - <40% doesn't attract quality affiliates
4. **No social proof** - Fake it with testimonials from beta testers
5. **Broken checkout** - Test on multiple devices before launch
6. **Missing follow-up** - No email sequence = leaving money on table
7. **Overpriced** - Above $297 without proven results
8. **Underpriced** - Below $47 with course content (undervalues)
9. **No bonuses** - Bonuses are the #1 conversion driver on Hotmart
10. **No affiliate contest** - Competition drives affiliate results
