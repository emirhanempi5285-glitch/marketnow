# KDP Best Practices

## KDP Select vs Wide
| Factor | KDP Select | Wide (all platforms) |
|--------|------------|---------------------|
| Royalty | 70% ($2.99-$9.99) | 70% Amazon + other platforms |
| KU reads | YES - page reads generate revenue | NO |
| Promotions | 5 Free Book days + Kindle Countdown Deal per 90 days | No Amazon-specific promotions |
| Exclusivity | 90-day exclusive on digital | Can publish everywhere |
| Best for | Fiction, series, mid-list | Non-fiction, reference, coloring books |

**Decision rule:** If your book generates >30% revenue from KU reads → stay in Select. If <10% → go wide.

## Category Strategy

### How to Get Into the Right Category
1. Amazon assigns based on BISAC code + keyword match
2. **Override by selecting specific categories in KDP dashboard:**
   - Choose 2 categories on submission
   - Add 2+ more via KDP Contact Support after publication
3. **Target subcategories with BSR <100K** for easier #1 New Release badge

### Best Categories for Ghost Rankings
- Look for subcategories where Top 20 BSR is <100K
- Underserved niches: Under 200 reviews in top 20
- Target: Get in top 5 of a small subcategory → cross-sell to larger categories

## A+ Content (Premium)

### Does A+ Content Help Ebooks?
KDP requires author-platform branding for A+. Use book description optimization instead:

**The VAKOG Description Pattern:**
```
[HEADLINE: Pain Point + Solution in 60 chars]

Are you tired of [FRUSTRATION]? 
Do you wish you could [DESIRED OUTCOME]?

Inside [BOOK TITLE], you'll discover:
✅ [Feature 1] → [Benefit]
✅ [Feature 2] → [Benefit]
✅ [Feature 3] → [Benefit]

Scroll up and click "Buy Now" to start your journey towards [TRANSFORMATION].
```

This converts 2-3x better than generic descriptions.

## Keyword Backend Optimization

### 7 Key Phrases Strategy
Each of the 7 keyword fields should target specific intent:

| Field | Intent | Example |
|-------|--------|---------|
| 1 | Broad category | adult coloring books animals |
| 2 | Problem/solution | stress relief coloring books for adults |
| 3 | Format + benefit | relaxation coloring book for adults anxiety |
| 4 | Demographic | coloring book for women relaxation hobby |
| 5 | Occasion/seasonal | valentines day coloring book for adults |
| 6 | Style/theme | intricate mandala coloring book detailed |
| 7 | Alternative search | zen doodle coloring book adult patterns |

**Rules:**
- No commas, no dashes (separate words)
- 249 characters max per field (use Character Counter)
- Include misspellings strategically (e.g., "colouring" for UK market)
- Don't repeat keywords across fields

## Pricing Psychology for KDP

| Price Point | Psychology | Best For |
|-------------|-----------|----------|
| $0.99 | Loss leader, review generation | First in series, new authors |
| $2.99 | Minimum 70% royalty, "bargain" | Short reads, promo pricing |
| $4.99-$6.99 | Sweet spot for single-author non-fiction | Most books |
| $7.99-$9.99 | Premium indie pricing | Comprehensive guides, workbooks |
| $12.99+ | Production quality pricing | Hardcover, illustrated |

**Paperback pricing:** Set at lowest end of similar books in your category + 40% margin minimum.

## Review Generation Strategy
1. **ARC copies** (Advanced Review Copies) → Booksprout, BookSirens
2. **KU readers** naturally rate more
3. **Back matter CTA:** "Enjoyed this book? Leave a review!"
4. **Email list:** Thank-you page → review request
5. **Target:** First 10 reviews within 30 days (algorithm boost)

## Common KDP Rejection Reasons
1. Bleed settings incorrect (book interior bleeds off page)
2. Cover spine width wrong (mismeasured)
3. Font licensing issues (embedded fonts not licensed for print)
4. Image resolution too low (<300 DPI)
5. Blank pages violating CPC (Cover Page Copyright) rules
6. Copyrighted content in title or keywords (trademark issues)
